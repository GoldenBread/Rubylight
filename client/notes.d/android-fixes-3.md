## en
- With Controllers set to Off, the PC no longer gets controllers that never send anything.
- With Controllers set to Off, a pad's mouse mode no longer says it is on when it cannot move the mouse, and the stream menu no longer offers the controller mouse switch.
- Turning or folding the device, resizing the window or an automatic quality change no longer freezes the app while the video decoder restarts.
- After the stream changes size, the picture no longer stays frozen for a moment when nothing on screen moves.
