## en
- Snapdragon GPU driver: when a custom driver such as Turnip falls back to the system driver, Nightjar now says why: the driver library did not load, it is not an Android Vulkan driver, it did not start Vulkan, it found no GPU it supports on this phone, or it lacks features PyroWave needs. The reason shows in the driver settings and the stream's GPU line, and the problem report's log names it, with the system's message for a library that did not load, such as a library the driver needs that this phone lacks.
