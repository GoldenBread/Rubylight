## desktop
- Reduced desktop and handheld power draw during streams and in the launcher: replaced busy-spin frame and fractional V-Sync waits with kernel high-resolution timer sleeps (keeping spin precision for Beam Race only), switched Windows SDR streams to an 8-bit sRGB swapchain instead of keeping a 16-bit floating-point scRGB swapchain whenever any profile or setting used shaders, replaced 1000 Hz SDL controller wakeups with adaptive polling, eliminated CPU spinning in Windows display-check scanline calibration, VRR scanline waits, and restart probes, used DXGI frame statistics for targeted VBlank sleeps in no-wait presents, and enabled Windows Wi-Fi media streaming mode only when the route to the PC is wireless.
