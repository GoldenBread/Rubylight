## en
- A TV remote's Back, and a handheld's Back set to open the stream menu, close the system keyboard during a stream. Before, Back opened the stream menu and the keyboard came back each time the menu closed.
- The stream menu's Keyboard tile (Y) closes the system keyboard when it was open, instead of opening it again.
- On the PC keyboard, Up from the top row selects the close button, so a remote or controller can close it with OK as well as with Back or B.
