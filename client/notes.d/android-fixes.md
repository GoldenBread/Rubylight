## en
- Typing during a stream no longer closes the stream when the on-screen keyboard asks for no text before the cursor.
- Leaving the shared-folders page just as an upload finishes no longer closes the app.
- Microphone only keeps the phone awake on devices that refuse the Wi-Fi lock, so the audio no longer stalls with the screen off.
- The controller test screen stops reading the phone's motion sensors once the controller is unplugged.
- Choosing a preset in the on-screen controls editor keeps the Steam Controller controls where you put them.
- With Controllers set to Off, the on-screen gamepad still works; only physical controllers are held back.
- The game list's background no longer shows another game's picture after you move back to the game it already showed.
- The controller test screen keeps showing a USB controller's motion after you leave it and come back.
