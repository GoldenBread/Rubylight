## en
- An invite that names a PC already in your list is refused before anything is sent, so the invite is not used up and the listed PC keeps its pairing and addresses.
- A game's page now waits while it starts a game or wakes the PC, instead of cancelling when you turn the device.
## desktop
- Controllers beyond the number the PC takes are refused with "This PC takes N controllers", still work in Nightjar's own menus, and get a slot when one is freed.
- A key or button release is no longer lost when the input queue is full, so the PC no longer sees a key or button stuck down.
- A failed settings or PC-list save is now told to you, with the folder Nightjar could not write to, instead of reverting silently at the next start.
- The first-run page says why the pairing key cannot be read instead of waiting for one.
- A game you start right after a stream no longer begins before the previous stream has finished ending.
