## 1. Where Rubylight & Nightjar Already Lead — And What NOT to Copy

Before adding a single item, the `/teamwork` team MUST protect the architectural advantages where Rubylight + Nightjar already outperform Parsec, Steam Remote Play, Sunshine/Apollo/Vibepollo, Artemis, Glimmer, and Chiaki:

| Area Where We Lead | Hard Invariant to Protect in 7.0.0 |
| --- | --- |
| **Zero-account, local-first privacy** | No login servers, no cloud profiles, no telemetry, peer-to-peer `rubylight-traverse` hole-punching & local QR/PIN pairing. |
| **Fewer-settings, outcome-first craft** | Smart automatic defaults, 4-section Nightjar IA, unified Visual Controller Editor replacing scattered flat keys (retiring `experimentalChipsetTuning` via `VendorKeyHangs` auto-quarantine rather than adding more checkboxes). |
| **Direct `rubylight-vdisplay` frame push (`idd-push`) + D3D12 compute** | Zero-copy driver push + single-pass D3D12 compute conversion with live dynamic HDR10+ / Dolby Vision / HLG luminance statistics. |
| **Frame Warp 2.0 + Real VRR + PyroWave & Beam-Racing** | Learned FOV + HUD depth-stability masking, DXGI present-timestamp VRR cadence, and wavelet sub-frame beam-racing — never trade away sub-frame latency for heavier compositor queues. |
| **First-party signed Rust UMDF2 `rubylight-vgamepad`** | Zero unsigned KMDF drivers; zero bundled third-party mods (`Nucleus Co-op` / `ANR` never bundled and never named in UI or Nightjar per GPL-3.0 §7(e)). |
| **Unified Rust `nightjar-core` + `nightjar-policy` & `RecoveryJournalV2`** | One protocol/policy/recovery truth shared across Android & Desktop; crash-safe transactional restore of displays, DPI, audio, and driver settings. |

### Competitor Ideas Deliberately REJECTED (Do NOT Build)
- **Mandatory accounts, cloud profile sync servers, or hosted SaaS TURN relays** (Parsec / Steam model) — contradicts our local-first privacy advantage; Hub Sync (`09`) and Traverse (`15`) stay 100% owner-hosted.
- **Persistent social friend lists / public Arcade lobbies** (Parsec) — `/guest` invite links already deliver frictionless zero-account co-play without social-platform bloat.
- **Settings-sprawl parity checkboxes** (Artemis / Sunshine forks exposing dozens of brittle raw driver/encoder knobs) — automate via probing & crash-guard sentinels instead.
- **Bundling third-party mods or unsigned KMDF input drivers** — forbidden by `AGENTS.md` and security posture.
