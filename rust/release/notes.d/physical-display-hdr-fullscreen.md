# Physical display HDR and exclusive fullscreen
- **HDR recovers after exclusive-fullscreen SDR apps and mode switches.** Mid-stream HDR-to-SDR fallback now waits through brief display mode transitions (2 seconds) instead of dropping on a single transient SDR frame, normalizes FP16 surfaces by Windows' SDR content brightness while in SDR, and automatically returns the stream to HDR with updated display metadata once capture reports HDR active again (#145).
- **Fresh Desktop Duplication colour readings on open.** Desktop Duplication now refreshes DXGI colour space and Windows SDR white level immediately after opening duplication when the DXGI factory went stale or the returned surface format disagrees with the pre-open reading, and reopens into FP16 if an 8-bit duplication session enters HDR without losing access (#145).
- **Physical display HDR turns back off after exclusive-fullscreen SDR apps.** Stream teardown and startup display recovery now also clear Windows' armed HDR switch when an exclusive-fullscreen SDR app temporarily suppressed the active HDR mode, so HDR does not snap back on after the stream ends (#145).
