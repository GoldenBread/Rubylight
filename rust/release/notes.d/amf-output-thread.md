# AMD encoder output
- **On AMD, a new picture no longer waits for the host's check on the encoder before it is encoded.** The encoder's output is now collected on a thread of its own. Beside a 60 fps GPU load at 1440p120, up to 2 % of pictures had waited about 1 ms there; at 4K120 with the GPU saturated, 7 % waited up to 2.2 ms. Now at most 0.3 % wait, for at most 0.06 ms, and the slowest encodes finish sooner. End to end latency did not improve. It costs about 3 % of one CPU core. Moonlight's host processing figure on AMD now reads about 0 ms, because it no longer includes the wait for the encoder. `amd_output_thread = false` brings back the old path.
