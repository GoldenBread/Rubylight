# PyroWave first-frame stall
- **Faster, stall-free PyroWave stream starts.** PyroWave no longer defers colour-conversion slot creation, D3D12 shader pipeline creation, and Vulkan compute pipeline compilation to the first captured frame inside the active streaming loop (#147). PyroWave encoders now allocate only the shared plane textures and single shared fence each slot uses, skip compiling unused D3D11 and `yuv420_cs` D3D12 shaders on the compute conversion path, compile `pyro_cs` eagerly, and run a creation-time Vulkan pipeline warmup before streaming begins. This also reports compute conversion status accurately immediately after PyroWave encoder creation.
