# Input reliability and permissions
- **Reconnecting controllers.** Virtual controllers stay attached across reconnects when non-hardware input settings or Steam launch state change, a guest connecting while the game's owner reconnects no longer evicts player 1, and changing controller profiles finishes unplugging the previous virtual pad before plugging its replacement (#164).
- **Quick Suspend and Couch Menu.** Pausing a game with Quick Suspend immediately stops active controller rumble and releases held keys, and opening the Couch Menu with a keyboard chord releases preceding modifiers in the same packet so `Ctrl` and `Alt` never stay stuck.
- **Window follow-focus and guest permissions.** Window capture updates absolute pointer and touch coordinates immediately when the captured window switches, hot-unplugging USB/IP controllers detaches in the background without stalling other pads, and view-only guests can no longer request text-input focus notices, report keyboard layouts, or route controller audio.
