# Capture
- **An exclusive-fullscreen game or emulator no longer freezes the picture on Automatic.** Windows Graphics Capture reads what Windows composes, and an app in exclusive fullscreen presents past that, so its picture stops with no error while the app keeps running. On Automatic, a streamed display that sends no picture for 2 seconds while Windows reports an exclusive-fullscreen app in front is captured with Desktop Duplication instead, which reads what the display shows, and the stream card says why. A named Capture method is never changed automatically; timing and HDR under Desktop Duplication can differ.
