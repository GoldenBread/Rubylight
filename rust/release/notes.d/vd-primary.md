# Virtual display stays the main screen
- **The virtual display stays the main screen with "Extend — make virtual display primary".** When a game or Windows moved the main screen back to your monitor, every later stream from that device started that way and the setting looked ignored. When Windows changes the displays by itself, such as a monitor arriving or leaving or coming back from the lock screen, the stream now puts the virtual display back as the main screen within about a second, and its card says so if Windows refuses or keeps taking it back. A main screen you pick yourself in Windows stays yours. Devices that kept the wrong layout follow your setting again.
- **Older device layouts now show as learned.** A layout a device kept from before this version shows as learned under Devices and follows the host's display layout; pick it again there if you want it kept.
- **The device page says when a stream set its layout.** Next to **Virtual display layout**, a learned layout reads "Learned from your last stream: …", and **Clear** makes the device follow the host setting again.
