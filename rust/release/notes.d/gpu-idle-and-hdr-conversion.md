# Lower GPU load while streaming
- **Idle frames and HDR conversion use less GPU.** AMF now reuses the last converted GPU texture on unchanged static repeat frames instead of re-running colour conversion and HDR luminance statistics at the idle frame rate. Unread frames dropped from the display driver's fence ring and keyed-mutex zero-copy capture now release their slots without queueing a D3D12 compute-queue fence `Signal`. HDR 4:2:0 colour conversion now filters linear BT.2020 light directly instead of round-tripping through PQ/HLG encode and decode per chroma tap; measured in release builds on an AMD Radeon RX 7900 XT at 3840×2160 HDR, GPU conversion time dropped from 0.315 ms to 0.192 ms (-39%) on the single-pass compute shader and from 0.485 ms to 0.297 ms (-39%) on the pixel-shader fallback (PyroWave 4:2:0 compute: 0.200 ms to 0.133 ms, -33%).
