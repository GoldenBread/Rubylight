# Frame generation
- **Neural Rendering is now frame generation.** A game's switch puts a third-party frame generation mod into games that ship DLSS frame generation: turn on DLSS frame generation in the game, and it takes its place. It is offered on Radeon RX 5000 and newer, the Radeon 780M among them, and on GeForce GTX 16, RTX 20 and newer, also when that GPU is a laptop's dedicated card beside the integrated graphics Rubylight streams with, downloads about 14 MB, and refuses games with a known anti-cheat. Leave it off for online games.
- A game that already has OptiScaler gets only the frame generation add-on, and its settings are put back exactly when it is turned off.
- Turning it off also removes what the mod writes into its own folder while a game runs, and names anything someone else left in the folders it made. While the game runs, turning it off changes nothing and asks to close the game. Final Fantasy XVI's first launch after turning it on spent about 10 minutes compiling its shaders on a Radeon RX 7900 XT; that launch also followed a driver update, so how much of the wait comes from frame generation is not measured.
- The earlier neural upscaling is no longer offered. A game that still has it shows it on its page with Remove, and turning frame generation on removes it first, only once the game passed every check, so a game that is refused keeps it; its 1 GB download is deleted.
- Paired Nightjar devices can turn a game's frame generation on and off when the device has Host control. The game page and the devices say before any try why a game can't have it: an anti-cheat, no DLSS frame generation, or its program to be chosen.
