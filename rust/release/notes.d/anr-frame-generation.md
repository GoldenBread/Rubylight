# Frame generation
- **Neural Rendering is now frame generation.** A game's Frame generation switch puts a third-party frame generation mod into a game that ships DLSS frame generation: turn on DLSS frame generation in the game, and the mod takes its place. It is offered when any of the PC's GPUs can run it: Radeon RX 5000 and newer, the Radeon 780M among them, or GeForce GTX 16, RTX 20 and newer. When that GPU is not the one Rubylight streams with, such as a laptop's dedicated card beside the integrated graphics that drive its display, the switch names it and says frame generation runs when the game renders on it. Intel graphics are not offered. It needs the Microsoft Visual C++ 2015-2022 Redistributable (x64) on the PC, downloads about 14 MB once, and refuses games with a known anti-cheat. Leave it off for online games.
- The game page says why a game can't have it before you try, with the switch greyed out: an anti-cheat, no DLSS frame generation, its program to be chosen, or the Visual C++ runtime to install on the PC. It turns on and off only while nothing is streaming.
- A game that already has an upscaler mod you installed gets only the frame generation add-on, and the settings it changes there are put back exactly when it is turned off.
- Turning it off also removes what frame generation writes into its own folder while a game runs, and names anything someone else left in the folders it made. While the game runs, turning it off changes nothing and says to close the game. Final Fantasy XVI's first launch after turning it on spent about 10 minutes compiling its shaders on a Radeon RX 7900 XT; that launch also followed a driver update, so how much of the wait comes from frame generation is not measured.
- The earlier neural upscaling is no longer offered. A game that still has it shows it on its page with Remove, which takes out only the earlier upscaling and leaves frame generation as it is. Turning frame generation on removes it first, only once the game passed every check, so a game that is refused keeps it, as does one where its removal would leave a changed file behind. Its 1 GB download is deleted.
- Paired Nightjar devices can turn a game's frame generation on and off when the device has Host control, and say why in their own words before any try.
