# Port forwarding
- **Port forwarding recovers when the network changes.** UPnP port forwarding kept the router it found when the host started: after another router took over, this PC got another address, or the router's UPnP stopped answering, the ports stayed closed until the host was restarted. A router that misses one renewal now keeps its mappings untouched; one that stays silent for two renewals in a row, by when their two-minute lease has run out, is looked for again, and the router found then maps the ports for the address this PC has now. The search for the router goes out on this PC's Ethernet or Wi-Fi network, not a VPN's.
