# Sessions
- **A game that waits for sign-in can be cancelled from its device.** A launch started after sign-in is now owned by the device that asked for it, so End session or Quit on that device cancels it while it prepares.
- **The Sessions page shows what the stream got against what was asked.** A stream the network held below its request reads "X of Y Mbps" instead of the lower rate alone.
