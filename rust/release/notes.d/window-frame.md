# Window's frame

- **Stream only what a windowed game draws.** With **What to stream** set to the app's window, the new **Window's frame** setting (`capture_window_frame`, `full` by default) can keep only the game's content, cropping the title bar and the borders before encoding. Input maps to the cropped content, and a game that draws its own title bar keeps it. Set it for every app, one app, or one app on one device, as for What to stream; the default stays the whole window.
