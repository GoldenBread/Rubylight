# On-screen Steam Controller controls with Automatic
- **The controller type Automatic picks the Steam Controller for Nightjar's on-screen Steam Controller controls in apps started through Steam.** It does so when the stream's app starts through Steam (Steam Big Picture, a `steam://` link, a `steam.exe` command or a game from the Steam library), Steam was running as the controller connected and the gamepad driver has the Steam Controller. Every other app, the Desktop included, keeps the Xbox-type controller; so does a Steam app without Steam running or with an older gamepad driver, and the stream then says what to do.
