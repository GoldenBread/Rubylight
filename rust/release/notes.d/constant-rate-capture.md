# Constant-rate capture

- **A game capped below the stream's frame rate keeps the stream at its full rate.** Capture method → Windows Graphics Capture, constant rate (`capture = wgcc`) sends the last picture again whenever the game has no new frame ready for a stream frame, so a 90 fps game on a 180 fps stream keeps one frame per stream frame instead of the encoder repeating a still picture between the game's frames, and a new game frame is never held back for its slot. Every repeat is encoded like any frame, so the stream spends its bitrate between the game's frames too, and a still picture keeps the full rate; leave it off on a mostly still screen. It applies to the launched app's window as well; on a display, Desktop Duplication keeps the rate when Windows Graphics Capture is unavailable. Off by default.
- **A configuration that already says `capture = wgcc` now turns this on.** Earlier builds read that Vibepollo spelling as plain Windows Graphics Capture; use `capture = wgc` for variable-rate capture. Configurations that never set it keep Automatic, so nothing changes for them.
