# Frame limiter
- **No frame limit without RTSS.** A virtual display's automatic frame limit is applied only when RivaTuner Statistics Server (RTSS) is installed. Before, a virtual display at 2x, 4x or 1000 Hz reported a limit that nothing applied, and the log said so on every launch. Now the display's own refresh paces the game, and the host says once per host run that RTSS is needed for the cap. A limit you set yourself still says on the stream that it was not applied.
