# Settings cleanup
- **One row each for HDR, the update schedule and an app's virtual display.** Display HDR has four choices, Match the stream, Always on, Always off and Don't change HDR, in place of a separate HDR request. Check for updates offers Daily at a set time beside its intervals. An app's Virtual display mode includes Always, which replaces the separate Use a virtual display switch. Saved settings, apps, per-device settings, restored backups and imported Sunshine, Vibepollo and Apollo profiles carry over.
- **Settings say when they do nothing.** A setting with no effect in the current setup shows as inactive with the reason: adaptive pacing while a Pacing rate is set, the frame limit while Limiter is None, or the virtual display's scale, HDR calibration and Vulkan HDR layer on Windows before 11 23H2. In the app editor, Make the virtual display primary, Keep a separate identity for each device and Legacy frame generation capture fix say when another choice takes their place.
- The app editor's Frame generation limiter fix is gone: the host never read it, and saved copies are cleared. The capture timing diagnostics (Capture poll interval, Predictive polling, Align capture with encoding) moved to Advanced → Debug switches.
- Virtual display refresh and Full chroma are stored as `virtual_display_refresh` and `packed_444`. Configurations, scripts and API calls that use the earlier names keep working.
