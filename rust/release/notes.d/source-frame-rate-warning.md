# Source frame-rate warning

- **The console says when the game or desktop holds the stream back.** When the source stays below 97% of the stream's frame rate for 15 seconds, the stream card shows about how many frames per second it is rendering and suggests lowering the game's settings or the stream's frame rate to match; the host log says when it keeps up again. A short dip, a level change or a still picture does not trigger it, and the console warning appears at every log level.
