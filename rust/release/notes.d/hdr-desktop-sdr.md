# HDR desktop on SDR streams
- **Keep HDR highlights in SDR streams.** A new option for an HDR desktop streamed as SDR: bright areas above Windows' SDR white are compressed (ITU-R BT.2446-1 Method B) instead of turning flat white, and the SDR content brightness slider no longer changes how the same light is coded. SDR white (windows, the desktop and the mouse pointer) then streams below full white: about 86% at 203 nits, and about 65% at the slider's minimum; the couch menu stays at full white. It is off by default because it costs GPU time on every frame: on the RX 7900 XT about 0.05 ms per 4K frame of grey content and about 0.5 ms of saturated content with the compute conversion, about 0.9 ms without it.
